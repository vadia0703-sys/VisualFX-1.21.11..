# VisualFX для Minecraft 1.21.11

Это Fabric-мод для Minecraft Java Edition 1.21.11 с клиентскими визуальными эффектами.

Сейчас мод добавляет декоративные частицы при наведении на блоки. Урон, здоровье и боевые характеристики не изменяются.

## Сборка с телефона

Самый простой вариант — загрузить весь проект в GitHub и запустить workflow:

1. Создай новый репозиторий на GitHub.
2. Загрузи в него все файлы и папки из этого проекта.
3. Открой вкладку Actions.
4. Запусти `Build JAR`.
5. После завершения открой результат workflow и скачай artifact `visualfx-jar`.
6. Внутри будет готовый `.jar`.

Для Minecraft 1.21.11 нужен Fabric Loader и Fabric API соответствующих версий.
